# Changelog

## 1.1 — 2026-11-24

- Corrected draft versus trial/interim status guidance and cited a formally issued interim instrument.
- Added coordinate-system, coordinate-order, and conversion-provenance guidance for map comparisons.
- Fixed the case-sensitive guide link, supplied the stated CC BY 4.0 license, and replaced editorial placeholders.
- Distinguished observed access outcomes from inferred causes and strengthened the English-name identity caution.
- Added a selective structured validation register with separate documentation and live-test status. No live search or GSXT access is claimed by this release.
- Added a reusable CSV evidence log and an offline synthetic procurement exercise with bilingual notices, completed log, and answer key.
- Added offline documentation checks, validation-data generation checks, regression tests, and a read-only GitHub Actions workflow.
- Added contribution instructions and labeled the uncited warning-banner text as an illustration rather than a documented observation.

Contribution credit: [zbl1998-sdjn](https://github.com/zbl1998-sdjn) raised access-outcome distinctions in [issue #1](https://github.com/ArgeliusLabs/chinese_osint_search_dorks/issues/1) and proposed the English-name matching caution in [PR #2](https://github.com/ArgeliusLabs/chinese_osint_search_dorks/pull/2). The general lessons are incorporated here. The vendor study is not used as independently validated quantitative evidence; the publisher's [corrected access write-up](https://currawongweb.com/verify/gsxt-error-521/) also withdraws stronger causal and browser-access claims from the original report.
